# سیستم تصمیم‌یار خرده‌فروشی ترکیبی انسان و هوش مصنوعی (HAI-Retail DSS)

[English Documentation](README.md) • [گزارش خطا و بازخورد](https://github.com/abbasi0abolfazl/HAI-Retail-DSS/issues)

یک سیستم پشتیبان تصمیم‌گیری (Decision Support System) شبیه‌سازی‌شده و تعاملی برای پیاده‌سازی و ارزیابی تعامل **ترکیبی انسان و هوش مصنوعی (HAI)**، هوش مصنوعی تفسیرپذیر (XAI)، مدیریت ریسک فازی و عدالت الگوریتمی (Fairness) در قیمت‌گذاری و تخصیص موجودی زنجیره خرده‌فروشی.

## 🔬 فرمولاسیون ریاضی و پارامترها

1. **ارزیابی مقدار حالت بر اساس فرآیند مارکوف (MDP):**
   $$V(s) = R(s) + \gamma \sum_{s'} P(s' \mid s, a) V(s')$$

2. **جریمه بی‌عدالتی مارجین‌ها (Margin Disparity Penalty):**
   $$L_{\text{bias}} = \beta \cdot \max(0, \, |m_i - m_j| - \tau)$$
   در این رابطه $m_i, m_j$ مارجین‌های سود در رده‌های مختلف محصول، $\tau$ آستانه تحمل و $\beta$ وزن جریمه است.

3. **پاداش نهایی سیستم:**
   $$R_{\text{adj}} = (R_{\text{base}} \cdot \text{Trust}) + 5 \cdot \text{Adapt} - L_{\text{bias}} - \mathbb{I}_{\text{human}} \cdot \text{Penalty}$$

## ✨ قابلیت‌های برجسته

- **رابط دسکتاپ مدرن با PyQt5:**
  - استایل‌دهی استاندارد و فرم‌های تنظیم برخط پارامترها.
  - نمودار پویا و دو‌محوره Matplotlib برای مقایسه تصمیم هوش مصنوعی در برابر تصمیم نهایی و پاداش خالص.
- **تغییر برخط ماژول‌ها برای مطالعات حذف (Ablation Studies):**
  - فعال/غیرفعال‌سازی کنترل ریسک فازی
  - فعال/غیرفعال‌سازی هوش مصنوعی تفسیرپذیر (XAI)
  - فعال/غیرفعال‌سازی مهار بایاس الگوریتمی
  - فعال/غیرفعال‌سازی مداخله دستی انسان
- **تله‌متری برخط و نمایش معادلات:**
  - نمایش هم‌زمان فرمول‌ها همراه با جایگزینی مقادیر عددی لحظه‌ای.
  - شاخص‌های زنده: میانگین پاداش، مجموع جریمه بایاس، نسبت مداخله انسانی و تعداد ماژول‌های فعال.

## 🛠️ نصب و راه‌اندازی

```bash
# ۱. کلون مخزن
git clone https://github.com/abbasi0abolfazl/HAI-Retail-DSS.git
cd HAI-Retail-DSS

# ۲. ایجاد محیط مجازی و نصب پیش‌نیازها
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

# ۳. اجرای نرم‌افزار دسکتاپ
python main.py
```
